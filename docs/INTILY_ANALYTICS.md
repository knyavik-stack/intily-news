# Intily — аналитика простым языком

**Дата:** 2026-09-07

## 1. Два экрана

### Intily AI News Publisher

Показывает только **текущий production cycle**: входной поток, фильтрацию, кандидатов, admission, публикацию, AI provider, audience-fit и media path.

### Intily Production Monitor

Показывает **историю системы** за 24 часа, 7 дней и сохранённую историю: публикации, кандидатов, причины отсутствия публикаций, здоровье источников, audience-fit, image delivery, provider/failover и последние циклы.

## 2. Актуальный score flow

```text
RSS / discovery
   ↓
base editorial score
   ↓
PRE-AI gate = 40
   ↓
AI переводит + пересказывает + оценивает audience-fit 1–10
   ↓
audience bonus = score × 2 (+2…+20)
   ↓
FINAL score
   ↓
FINAL publication gate = 55
   ↓
Telegram
```

**55/100 — текущий финальный порог публикации.** Старые упоминания финального порога 60 в исторических документах не являются текущей настройкой.

Pre-AI 40 не означает автоматическую публикацию. Кандидат 40–54 сначала проходит AI-редактуру и audience-fit; только итоговый score 55+ допускается к публикации.

## 3. Audience-fit

AI оценивает практическую полезность для русскоязычного AI-активного профессионала: предпринимателя/владельца бизнеса, руководителя, product/marketing/sales/operations/finance специалиста, разработчика, AI-практика или power user.

| Audience score | Bonus |
|---:|---:|
| 1 | +2 |
| 2 | +4 |
| 3 | +6 |
| 4 | +8 |
| 5 | +10 |
| 6 | +12 |
| 7 | +14 |
| 8 | +16 |
| 9 | +18 |
| 10 | +20 |

Это редакторский сигнал, а не демографическое утверждение о реальных подписчиках. После накопления фактической Telegram-статистики его можно будет калибровать по просмотрам, пересылкам, реакциям и другим измеримым результатам.

## 4. Media analytics

Для каждого цикла фиксируются попытка, найденное изображение, валидация, отправка фото, text fallback, причина, источник, URL статьи, размеры и размеры payload.

Текущая политика:

- источник изображения — publisher-first;
- Google News — только discovery wrapper, не допустимый image host;
- изображения **>1,000,000 bytes** — жёстко отклоняются без resize/recompress;
- при наличии нескольких publisher candidates oversized/broken candidate пропускается, следующий кандидат проверяется;
- длинный текст статьи больше не должен сам по себе переводить публикацию в text fallback: для фото строится безопасная caption-версия ≤1024 символов;
- если подходящей картинки нет, текстовая публикация остаётся допустимым fallback.

## 5. Как читать отсутствие публикации

`candidate_count` — размер входа, а не причина блокировки. Реальные блокировки: duplicate/known history, уже опубликовано, уже в очереди, final score ниже 55 после audience-fit, ещё не истёк publication interval, либо ошибка AI/Telegram.

## 6. География

Целевой портфель — около **40% RUSSIA / 60% WORLD**. Это portfolio objective. География не добавляет баллы к математической релевантности и не должна создавать искусственные публикации.

## 8. Что наблюдаем дальше

Основные production KPI:

```text
supply
→ base score
→ AI audience-fit
→ final ≥55
→ publication
→ image/photo outcome
→ Telegram response
```

Наблюдаем фактический поток, а не пытаемся искусственно поднять количество публикаций.
