## Scoring v3

Run #474 proved the v2 model can admit a real story, but its distribution is still too compressed: only 3 of 446 inputs reached 60+. Therefore v2 is not accepted as the final editorial model.

The current `main` contains scoring v3, which changes the mathematical structure rather than lowering the threshold:

- 20 AI relevance
- 10 AI specificity
- 20 impact
- 25 event materiality
- 8 practical value
- 7 source quality
- 5 evidence
- 5 freshness
- novelty is deliberately removed from the numeric score
- low-signal penalty remains −6

The key change is an explicit event taxonomy: launch/release/deal/funding/research/policy/incident receives a bounded event-materiality base. Major actors, major-event signals and measurable consequences refine the score. Keyword repetition cannot manufacture an event.

Uniqueness is not scored. Semantic story memory remains the sole duplication mechanism.

### Editorial bands

- 0–59.9: reject
- 60–74.9: normal publication candidate
- 75–84.9: major industry event
- 85–100: exceptional/channel-defining

## Media release

Run #474 published the selected story as text because image resolution returned `ARTICLE_SOURCE_UNRESOLVED`.

The root cause is current Google News RSS behavior: article wrapper URLs may no longer resolve through an ordinary HTTP redirect. Google News currently exposes decoding parameters that can be used to resolve the publisher URL through its `batchexecute` endpoint.

A dependency-free resolver was added as `scripts/intily_google_news.py` and is now executed before the image pipeline. The image pipeline therefore receives the real publisher URL whenever Google resolution succeeds.

The resolver is fail-open: if Google resolution fails, Intily still publishes text rather than blocking the news cycle.

New regression tests cover:

- non-Google URL passthrough;
- Google decoding parameter extraction;
- `batchexecute` publisher URL parsing;
- existing publisher-image extraction;
- invalid-first-candidate recovery;
- Blockchain.News expected-image candidate.
